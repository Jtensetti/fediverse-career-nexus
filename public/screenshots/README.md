# Interface screenshots

These images are captures of Nolto's real public interface, taken on 22 September 2026 after the demo data was removed. They contain no invented profiles, jobs or posts. Capture the corresponding public routes again when the interface changes; do not populate production with sample content for marketing images.

- `jobs.jpg`: the `/jobs` page and its search controls.

The homepage supplies alternative text. Images are hosted locally so viewing the homepage does not contact an external image service.
